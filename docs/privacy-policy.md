# Privacy policy for Virotech contact processing

This contact form is designed to collect the minimum information necessary to respond to a project inquiry.

We collect:
- full name
- work email
- company name (optional)
- phone number (optional)
- selected service categories
- budget range
- project description

Purpose:
- respond to your inquiry
- understand project scope
- send follow-up communication
- manage internal sales and support workflows

Data handling:
- form submissions are sent to the backend service using HTTPS
- the backend sends the message via Hostinger SMTP to the support inbox
- the data is not stored in a public database by default
- credentials are kept in environment variables only

Retention:
- data is retained only as long as required for business communication and support operations

Your rights:
- you may request to review or delete your submitted information
- email support@virotech.in to request removal or correction

We recommend that users avoid sending confidential or regulated information through the public contact form unless there is a prior agreement in place.
